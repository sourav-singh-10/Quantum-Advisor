# Quantum Advisor — Project Synopsis

**Problem.** A retail investor in India who wants to decide whether to buy, hold or sell a stock has to combine several kinds of evidence: price trend and volatility, company fundamentals, recent news, and — most often ignored — whether the stock suits *their own* age, experience, risk appetite, horizon and goals. These signals usually live in different tools and often point in different directions, and the investor is left to reconcile them alone.

**Solution.** Quantum Advisor is a multi-agent system in which nine LLM-driven agents work together like an investment committee. A **Planner** decides which analysts a request needs and gives each a specific instruction. The **Market**, **Fundamentals** and **News** analysts run in parallel; the Market and News analysts choose their own data sources and switch to another source when one fails. The Planner reviews their results and re-plans when an analyst fails. A **Strategy** agent then proposes BUY / HOLD / SELL, and a **Risk Manager** critiques it against the investor's risk capacity — approving, asking for a revision with numbered objections, or vetoing — for up to three rounds before the Planner arbitrates. A **Portfolio** agent sizes the position from the investor's real portfolio value, and a **Report** agent explains the outcome, including where the agents disagreed. Every message between agents is streamed live to the user interface and saved as an execution trace. Deterministic tools do all data fetching and calculations, so the LLM decides and explains but never invents numbers; if the LLM is unavailable, each agent falls back to its rule-based path and says so.

**Target user.** Beginner-to-intermediate retail investors on NSE who want a second opinion that is personalised and explains its reasoning, and students learning how investment decisions are made. It is an educational decision-support prototype, not a substitute for a SEBI-registered investment adviser.

**Scope change since CA2.** The CA2 version ran a fixed sequence of rule-based steps with one LLM call for explanatory text, and its web page could silently replace the backend's result with a hard-coded price table. For CA3 we (1) made every agent take its own LLM decisions with typed outputs, (2) added the Planner with re-planning and arbitration, (3) turned the single risk check into a multi-round Strategy ↔ Risk critique, (4) replaced placeholder fundamentals with real data, (5) added memory of previous runs, (6) removed the hard-coded frontend engine and added a live agent-conversation view, and (7) replaced the event log with a message-level execution trace.
